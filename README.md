# 🗻 Viaje a Japón — Septiembre 2026

Guía web del viaje, pensada para usarse desde el móvil durante el viaje (funciona offline, instalable como app).

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

El despliegue a GitHub Pages es automático (GitHub Actions) en cada push a `main`.
